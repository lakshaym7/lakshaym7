## 🚀 Projects

### Agentic AI Pipeline for Healthcare Claims Review
A multi-agent backend that reviews claims against payer policy using RAG across four agents, reaching 100% top-1 policy retrieval accuracy. It includes deterministic human-in-the-loop guardrails that intercept LLM outputs when confidence drops below 70% or a billing-code conflict appears, and a 46-test suite covering guardrails, retrieval quality, and end-to-end correctness.
[Repo](#)

### QMuTrf, Quantum-Infused Multimodal Transformer for Radiology Captioning
A hybrid quantum-classical model that pairs vision transformers (ViT, DEiT, BEiT) with variational quantum circuits and a GPT-2 decoder to generate chest X-ray reports. Quantum transfer learning lifted BLEU and ROUGE scores across all backbones, with the best configuration reaching a ROUGE-L of 0.614.
[Repo](#)

### Multimodal DL Framework for Pancreatic Cancer Prognosis
A multimodal fusion framework integrating CT imaging, genomic, proteomic, and clinical data for patient risk stratification, with a confidence-scoring component that captures tumor heterogeneity beyond standard prognostic factors. Manuscript under review.

### SimVLA
A vision-language-action model for language-conditioned robotic manipulation. It takes a natural-language instruction with visual input and outputs robot actions.
[Repo](#)
